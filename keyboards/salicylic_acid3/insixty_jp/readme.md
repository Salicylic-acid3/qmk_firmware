# InSixtyJP

![InSixtyJP](https://cdn-ak.f.st-hatena.com/images/fotolife/S/Salicylic_acid3/20250908/20250908001428.png)

60% Split keyboard, Japanese layout.

* Keyboard Maintainer: [Salicylic-acid3](https://github.com/Salicylic-acid3)
* Hardware Supported: RP2040
* Hardware Availability: 準備中（[Build guide](https://salicylic-acid3.hatenablog.com/entry/in60jp-build-guide) 内に販売ページは未掲載）

Make example for this keyboard (after setting up your build environment):

    make salicylic_acid3/insixty_jp:default

Flashing example for this keyboard:

    make salicylic_acid3/insixty_jp:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
